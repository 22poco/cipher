# project overview

## overview

cipher is a cybersecurity learning platform built for AP cybersecurity students.

the platform allows students to learn through lessons, videos, quizzes, case studies, and hands-on cybersecurity activities.

teachers can manage course content through an admin dashboard and monitor student progress.

---

## goals

- provide a structured AP cybersecurity learning experience
- organize content into units, modules, and lessons
- support quizzes, videos, and case studies
- track student progress and quiz performance
- allow instructors to manage content without editing code
- support access both inside and outside the school network through NetBird

---

## users

### students

students can:

- create accounts
- sign in
- access course content
- complete quizzes
- complete case studies
- use cybersecurity learning tools
- track their progress

### teacher/admin

teacher can:

- manage lessons
- manage quizzes
- manage course structure
- monitor student progress
