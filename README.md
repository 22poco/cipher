<h1 align="center">cipher</h1>

</p>

## features

- student accounts
- units, modules, and lessons
- quizzes and progress tracking
- case studies
- code editor
- admin dashboard

## tech stack

- next.js
- tailwind css
- fastapi
- python 3.12
- postgresql
